## Shared production prompt

Use case: stylized-concept.
Asset type: production mobile game bottom-navigation icon for GRIDSHARD, a sci-fi tactical strategy game for ages 13+.
Primary request: create ONE isolated painted object icon, not a whole UI, not an icon sheet.
Style/medium: polished hand-painted 2.5D game UI illustration, tangible sculpted volume, softly beveled edges and convincing material separation. Professional, confident and original; no babyish toy look, no generic flat vector clipart, no emoji, no photorealistic product shot. Keep detail broad enough to read at 36–56 px.
Composition: square asset, one compact centered object with balanced optical weight, occupies about 82% of the canvas, 9% clear margin on every side. Mild three-quarter view with a slight top view; front face dominant, small right side visible. Nothing cropped.
Lighting: one broad upper-left key light, gentle cool reflected light, darker right/lower surfaces and subtle self-shadow/ambient occlusion. Rounded highlight shapes, not mechanically straight triangles. No floating halo, no bloom spill, no ground or environmental shadow outside the object.
Common materials: brushed steel, gunmetal, painted/enamel surfaces, restrained gold trim and a small turquoise energy detail. Rich but controlled color; no chrome mirror reflections or noisy microtexture.
Background: genuinely transparent alpha, clean antialiased edges, no white fringe, no checkerboard painted into the image.
Constraints: absolutely no letters, text, numbers, watermark, logo, UI button plate, frame around the asset, scenery, detached decorative particles, duplicate objects, or other game's identifiable artwork. Original GRIDSHARD art, with the craftsmanship and small-scale clarity of a premium mobile strategy game's icons.
