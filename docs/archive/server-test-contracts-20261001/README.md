# Tarihsel sunucu test sözleşmeleri

1 Ekim 2026. Bu 67 dosyanın test gövdeleri silinmedi; artık ürünün uygulamadığı Beta.28–62 mekanikleri ve kaldırılmış web-test yönetim uçlarının geçmişi olarak burada korunuyor. Bunlar aktif test koşusunda skip/xfail ile saklanmıyor ve aktif release test kapsamı sayılmıyor. Başarısız test sayısını düşürmek için canlı bir davranış çıkarılmadı; mevcut kanonik motor/API önce incelendi. Aktif sandık dengesi testi arşivlenmedi, yeni mağaza sözleşmesine uyarlandı.

Eski testlerin etkinleştirilmesi generator, swap/move, güç üstünlüğü veren çekirdek enderliği, laboratuvar veya HTTP'den canlı veri restore kararlarını geri getirmemelidir. Kanıt: app/game/engine.py komut listesi, app/game/board.py 5x3 NORMAL/CORE, app/game/core_balance.py Beta.72 açıklaması, app/telemetry.py olay beyaz listesi ve main.py aktif rota listesi.

Yeni negatif testler her tarihsel HTTP yolu için GET/POST isteğinin 410 ile kapanmasını, actor/profil/telemetri yazılmamasını; emekli komutların bakiye/konum değiştirmemesini; eski audit telemetrisinin kabul edilmemesini denetler. Pozitif karşılıklar mevcut enerji/ısı/imza, mağaza/ekonomi/kalıcı sonuç, offline restore, startup ve iki-istemci reconnect testleridir. Gerçek PostgreSQL/Redis/container/native kapıları ayrıca korunur. Ham eski sayımlar ile yeni aktif sayımlar doğrudan aynı test toplamı değildir.

Tam dosya/test/rota envanteri manifest.json içindedir; gerekirse arşivden geri alınabilir. Şunlar salt okunur referanstır, production image veya mobil web paketine kopyalanmaz.
